# Draftsim pick-order page catalog

Discovered from Draftsim's [simulator sitemap](https://draftsim.com/simulator-sitemap.php) on 2026-10-01. The sitemap contained 74 pick-order pages (including the Arena Powered and Vintage Cubes). This is a discovery snapshot; availability and ratings can change.

Imported snapshots:

- [Wilds of Eldraine (WOE)](https://draftsim.com/WOE-pick-order.php): 324 card ratings, from the page's generated `myrating` data. The page reports its latest update as October 23, 2023.
- [Reality Fracture (FRA)](https://draftsim.com/FRA-pick-order/): 295 rows from the pick-order app's embedded set list; five basic lands carry Draftsim's `-1` no-rating sentinel and are excluded by the app's 0-5 rating loader.

Neither imported source provides card-specific prose comments. The CSV `comment` column is intentionally present and blank so comments from other sources can be retained and displayed.
